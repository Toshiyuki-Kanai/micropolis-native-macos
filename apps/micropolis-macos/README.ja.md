# Micropolis Native macOS — Gameplay / 1.0候補

2026-10-22更新。既存Micropolis C++エンジンを使う、macOS 27以降・Apple Silicon向けの変更版です。Electronic Artsの製品ではありません。Swift 6 / SwiftUI / Canvasと既存のMicropolisNativeローカルSwift Packageを利用し、WebView・Electron・WASMは使用しません。

## 起動と基本操作

`MicropolisMac.xcodeproj`をXcode 27.1以降で開き、Scheme `MicropolisMac`、実行先`My Mac`で⌘R。起動時は地形を生成して停止状態で表示します。ローカル用アドホック署名、App Sandbox有効。配布用署名・公証は未設定です。

1. 空き地に道路を延ばし、道路に隣接する住宅・商業・工業地区を配置します。
2. 石炭または原子力発電所を配置し、送電線で各地区へ接続します。
3. 開始ボタンでシミュレーションを進めます。成長・交通・電力・人口・財政はすべてC++エンジンが計算します。
4. 都市情報の「都市評価」で需要と問題を確認し、「予算・税率」で財政を調整します。
5. ⌘Sで保存。アプリを終了し、保存した.ctyを開き、開始を押して続きを遊べます。

人口・評価は読込後にエンジンが再集計するため、更新前は「人口 集計待ち」と表示します。マップや資金を消去したという意味ではありません。保存形式に乱数列や停止中の実行状態は含まれず、ロード時に派生タイル等が更新される既存仕様は維持しています。

## ファイル操作

**1.0はアプリ1プロセスにつき都市ウインドウ1つの単一ウインドウ方式です。** 新規・開く・最近の都市・Finderからのオープンは、現在の都市を未保存確認後に置き換えます。複数ファイルを渡した場合も同じウインドウで順に処理します。都市ウインドウを閉じた後は、ファイルメニューの新規／開く、またはウインドウメニューから再表示できます。ライセンス表示は別の補助ウインドウです。

- 新規都市：⌘N。現在の都市を置換します。未保存の建設・時間進行・設定変更があれば保存／キャンセル／保存しないを確認します。
- 開く：⌘O。classic 27,120バイト、map+mop 51,120バイトの.ctyに対応。読込後は停止して開きます。
- 保存：⌘S。別名で保存：⇧⌘S。初回保存にはmacOS標準の保存パネルを使います。
- ファイルメニューの最近使った都市は最大10件。sandbox用bookmarkを保存します。権限が失効した場合は「都市を開く」から選び直してください。
- FinderやLaunchServicesから.ctyを渡して開く経路にも対応します。
- ウインドウを閉じる／アプリ終了時も未保存変更を確認します。保存失敗やキャンセルでは処理を中止し、現在の都市を保持します。
- 初回の未編集地形は未保存変更として扱いません。自動保存・Undoはありません。

URLのsecurity-scoped accessとNSFileCoordinatorを使用します。macOSのitemReplacementDirectory内へC APIで書き出し、成功後に標準ファイルAPIで保存先を置き換えます。保存パネルが許可していない隣接ファイルは作成しません。失敗時に既存保存先を壊しません。読込／保存時のファイル内容を保持し、保存先が外部で変更されていれば上書きを拒否して別名保存を案内します。電源断に対するfsync保証は含みません。

|---|---|---:|

| 住宅 / 商業 / 工業 | クリック、3×3 | 各100 |
| 公園 / 撤去 | クリック・ドラッグ | 10 / 1 |
| 石炭 / 原子力発電所 | クリック、4×4 | 3,000 / 5,000 |
| 警察署 / 消防署 | クリック、3×3 | 各500 |
| スタジアム / 港 | クリック、4×4 | 5,000 / 3,000 |
| 空港 | クリック、6×6 | 10,000 |

病院は住宅需要に応じてエンジンが自動生成します。病院の直接建設と学校は既存ツールに存在しないため、見かけだけのツールは追加していません。地形編集・ネットワーク拡張ツールは今回UIに公開していません。

左サイドバー・建設メニューで選択。キー1〜9は道路・住宅・商業・工業・撤去・送電線・鉄道・公園・石炭です。マップ上の枠は建設範囲の目安で、可否を保証しません。C++のアンカーに合わせ、複数タイルの建物はクリック位置の左上1タイルから範囲を確保します。

ドラッグは4方向で接続される経路へ補間し、同じストローク内で重複操作しません。受理した建設入力を直列処理してから保存等へ進みます。場所ごとの建設拒否はステータス欄で報告し、ドラッグ中に大量のダイアログを出しません。

- パン：右／中ボタンドラッグ、トラックパッド2本指スクロール。
- ズーム：ピンチ、マウスホイール、⌘／⌥スクロール、拡大縮小ボタン。1〜12倍。
- 「全体」でズームとパンを戻します。マップ外や余白に建設しません。
- リサイズ時も同じ座標変換を使用し、パン範囲を制限します。

## 描画と情報

GPL公開版Micropolisの16×16タイル画像をCanvasで描画します。公開元の固定Commitから取得したtiles.xpmを無損失でPNGへ変換し、原本・出典・GPL／EA追加条件をアプリのOriginalGraphicsフォルダに同梱します。ライセンスとクレジット画面から文書を参照できます。既存の合成画像・追加タイルセットは使用しません。

タイルIDは状態フラグを除いた下位10ビットです。0〜955の原画像を使用し、現エンジンの拡張教会等（956〜1023）は簡易色表示へ戻します。画像を読み込めない場合も簡易描画で操作を継続できます。区域の発展やインフラの接続はエンジンが返したIDに従って表示します。

16×16タイル単位の画像区画をactor上で組み立て、可視範囲だけをCanvasへ描きます。画像番号が変わった区画だけを再生成し、パン・ズームではキャッシュを再利用します。Retinaの画面座標と画像の画素を分離し、画像補間を無効にしてドット絵を維持します。12,000個のSwiftUI Viewは作りません。建設プレビュー・電力表示は画像の上に重ねます。

火災・交通・噴水・煙・レーダー・スタジアム・原子力施設等のタイルアニメーションは既存C++のanimateTiles()を約100msごとに呼びます。一時停止・停止時は静止します。元のテーブルで静止している水面・森林は静止のままです。列車・ヘリ・飛行機・船・怪獣・竜巻・爆発はC++の座標とフレームに従い、GPL原版の57フレームで描画します。効果音はmacOSのNSSoundで再生し、シミュレーションメニューでON/OFFできます。

電力表示をオンにすると、区域中心は通電なら黄・未通電なら赤になります。その他の導電タイルには黄色の枠を表示します。導電タイルの枠自体は通電保証ではありません。通電区域数・未通電区域数はエンジンの集計値です。

開始／停止は⌘R、実行開始後の一時停止／再開はスペース。低速・中速・高速・超高速を選べます。表示更新とエンジン更新は分離し、専用actorが100msごとに通常8 tick、超高速40 tickを実行します。メインスレッドにシミュレーション計算を置きません。

予算（⌘B）は税率0〜20%と道路・警察・消防の配分0〜100%。自動予算は切替可能で、手動時は決算直前で停止し、設定の適用・承認後にエンジンが精算します。設定の適用だけでは自動予算へ切り替わりません。現在の人口・地価・施設数を使う年次見積りは仮エンジンで計算し、実都市の資金を変えません。開いた時の設定へ戻すボタンと起動中の財政明細があります。承認待ちは保存形式に含められないため、先に決算を承認してから保存してください。

都市評価（⌘E）では評価点・支持率・都市規模・資産・RCI需要・交通・汚染・犯罪を表示します。需要の正負や交通・電力の状況を見て地区・インフラ・税率を調整してください。災害メニューで自然災害を切り替え、確認後に6種類の災害を発生させられます。都市の状態によって被害が起きない場合もあります。

## MicropolisJ v2.0.0準拠機能

機能の基準はユーザー承認済みのdheid/micropolis、Tag v2.0.0、Commit `4cbac80d8d0052cbc9f4e71130dad212dbe2b492`です。JavaのUIやコードを移植せず、既存C++を使うmacOS標準の操作で提供します。内部アルゴリズムの完全一致は必須とせず、予算計算・年次見積りはユーザー承認済みのC++方式を維持します。[全機能比較表・エンジン差異](../../documentation/notes/engine/native-macos-micropolisj-parity.ja.md)を参照してください。現時点で完全な機能同等性の受け入れ完了とは扱いません。

- 新規都市では前/次の地形を確認し、初級20,000・中級10,000・上級5,000から選びます。候補の取消で実都市は変わりません。難易度・自動撤去はシミュレーションメニューでも変更可能です。
- 建設はマウスを離すと確定し、押している間にC++の仮配置と料金を表示します。Escapeで取消。住宅・商業・工業は3×3間隔、公園・撤去は1×1間隔の矩形選択、道路・鉄道・送電線は経路ドラッグです。施設はドラッグ終点へ配置します。資金不足ならそのストローク全体を取り消します。
- 「区域調査」を選んでクリックすると、建物区分、人口密度、地価、犯罪、汚染、成長を表示します。無料です。
- マップ選択で区域別・交通網、人口密度、成長、地価、犯罪、汚染、交通量、電力、消防・警察管轄を表示します。概観マップのクリック/ドラッグで移動します。矢印キーでもパン、Shift付きで大きく移動します。
- 履歴グラフ（⌘G）は6系列と10年/120年。都市通知（⌘M）は最大128件と災害等の場所への移動。需要は常時の棒グラフでも表示します。
- 補助マップが空なら保存はJava版が読める27,120-byteのclassic .ctyです。補助データがあれば失わないよう従来の拡張形式を保持します。後者と拡張教会タイルはJava版との互換範囲外です。財政明細・乱数・停止中の実行phaseは既存保存形式に含まれません。

## ビルドと自動テスト

リポジトリルートから：

```sh
./apps/micropolis-macos/script/build_and_run.sh --verify
./apps/micropolis-macos/script/verify_engine.sh
bash ./apps/micropolis-macos/script/verify_sandbox_save.sh
bash ./apps/micropolis-macos/script/verify_window_lifecycle.sh
bash ./apps/micropolis-macos/script/verify_graphics.sh
# 固定v2.0.0の別途取得済みソースを渡してJava相互保存を確認
bash ./apps/micropolis-macos/script/verify_java_compatibility.sh /path/to/pinned-v2.0.0-source
make -f packages/micropolis-engine/native.mk SANITIZE=1 -j4 \
  CXX='xcrun clang++ -arch arm64' CC='xcrun clang -arch arm64' test
```

`build_and_run.sh`は未保存都市を保護するため既存インスタンスを強制終了せず、ビルドした.appを別プロセスとして開きます。これは開発用であり、同じ保存先を複数プロセスで同時編集する運用は対象外です。テスト後の不要なウインドウは通常の閉じる操作で終了してください。`--debug`、`--logs`、`--telemetry`も使えます。

`verify_sandbox_save.sh`はログイン中のmacOS GUIセッションで実行します。独立した署名済みApp Sandbox検証アプリに、使い捨て都市1ファイルだけをLaunchServices経由で渡します。旧方式の隣接一時ファイル作成が拒否されること、新規保存・上書き・再読込・状態復元が成功することを確認します。実行中のゲームは終了しません。標準保存パネル自体のクリック操作はこの自動試験に含みません。

`verify_window_lifecycle.sh`もGUIセッションが必要です。実際のCityWindowBridge／CityFilesを使い、独立したテスト用ウインドウの閉じる処理・再表示時の登録・delegate転送・未保存保護を検証します。ユーザーのゲームウインドウは操作しません。

出力はGit管理対象外の`build/micropolis-macos/`、`build/native/`、`build/native-sanitized/`、`build/macos-app-validation/`、`build/gameplay-validation/`です。Xcodeからの実行は通常のDerivedData設定に従います。Swiftマクロを制限するsandboxでは、Xcode/マクロプラグインを実行できる実行権限が必要です。

C++/C APIは既存回帰に加え、全15ツール、電力・人口成長、保存後のエンジン破棄・再生成・復元、財政設定、長時間tick、繰り返し読込、災害を検証します。Swiftは実際のEngineSession/CityModelを使い、ドラッグ費用・保存前入力処理・失敗保存保護・復元継続・パン／ズーム座標を検証します。既存Web/WASMの13ファイル・80テストも成功しました。

## 外観・言語と画面配置

アプリメニューの「設定…」（⌘,）で外観を「システムに合わせる／ライト／ダーク」、言語を「システムに合わせる／日本語／English」から選べます。設定は次回起動時も保持し、アプリの表示は切替時に更新します。都市や未保存変更は保持します。言語切替時は建設中のプレビューを取消し、マップの表示位置を全体へ戻します。ライセンス原文・都市名・ファイル名は翻訳せず表示します。OSが管理する標準ファイルパネル内部の文言はmacOSの言語設定に従います。

建設ツールは左サイドバーの一覧から選択し、下部に概観マップを固定表示します。小さいウインドウではツール一覧をスクロールできます。左右の境界をドラッグすると、サイドバーをウインドウの半分以上まで広げられます。最大幅はウインドウ全体の75%で、右ペインの最小幅320ptも確保します。ウインドウを縮めた場合も上限が追随し、境界がウインドウ外へ出ないようにします。Construction ToolsとOverview Mapの境界も上下に動かせ、幅と高さに応じて概観の大きさが変わります。標準のサイドバーボタンで左右に開閉します。サイドバーは全高を使い、建設ツールと概観は同じグレーの背景です。Darkモードではサイドバーをウインドウ背景より少し明るいグレーにします。Light／Darkとも、サイドバー背景はツールバー上端までつながり、スクロール中の項目は標準の半透明ツールバー越しに表示されます。Dark専用の不透明なツールバー背景は使用しません。Lightモードの配色は従来どおりです。概観マップは表示枠の内側からドラッグすると、つかんだ位置と現在の倍率を保って主画面が移動します。枠外のクリックで、その位置へ移動します。Map Displayと拡大・縮小・全体表示はツールバーから操作します。資金・人口・年月などのバーとメッセージバーは右ペインの下部だけに表示します。情報は16〜18ptの固定幅セルで表示し、数値の桁数では位置が変わりません。右ペインが狭くなると2段以上に折り返します。

ツールバーは左が「再生」、右が「停止」です。実行中は再生が無効、停止中は停止が無効です。スペースとシミュレーションメニューによる一時停止／再開も維持しています。下部のメッセージは14ptに拡大し、ポインターを重ねると全文を確認できます。

道路・鉄道・送電線などのドラッグ中は、入力を仮エンジンへ順次反映し、プレビューの配置・接続・費用を表示します。マウスを離すまで実都市と資金は変更せず、Escapeで取消します。画像区画の更新待ちでは、既存の画像を維持しながら変更されたタイルを原画像で上書きします。アニメーションや建設で1タイルが変わっても、区画全体を簡易表示へ切り替えません。

ツールバー左側は標準サイドバー切替、新規、開く、保存の順。都市名は右ペイン側に表示します。右側は再生・停止、速度、倍率、マップ表示、電力、都市情報の順です。マップ表示はアイコンから14項目を直接選び、現在の項目にチェックを表示します。開く・保存は従来の未保存確認と安全なファイル操作を使用します。
